# Web UI Testing & LXC 100150 Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a lightweight, responsive Web UI dashboard for OSC (Open Security Checker) testing, containerize it with Docker Compose, configure Traefik File Provider routing for `osc.yowman.my.id` on LXC 100150, configure GitHub Actions self-hosted runner, and update `docs/HOMELAB-SSOT.md`.

**Architecture:** A FastAPI backend (`osc/web/`) provides REST APIs and background task orchestration wrapping `EnhancedOSCScanner`, serving a modern Tailwind-styled single page dashboard with live scan logs and report viewers. Containerized via Docker Compose on LXC 100150 (`192.168.0.150:8000`), routed via Traefik File Provider on LXC 10080 (`192.168.0.80`), and deployed via a self-hosted GitHub Actions runner running on the same LXC 100150.

**Tech Stack:** Python 3.12, FastAPI, Uvicorn, Tailwind CSS, SSE/Polling for scan progress, Docker & Docker Compose, Traefik v3.1 File Provider, GitHub Actions Self-Hosted Runner.

**Spec:** User interview requirements: Web Scanner Dashboard for OSC, FastAPI + HTML/Tailwind, `osc.yowman.my.id`, LXC 100150 (`192.168.0.150/24`), Cloudflare Zero Trust Access, systemd GitHub Actions runner on host LXC.

## Global Constraints

- Preserve all existing 170 pytest tests in `tests/`.
- Maintain AST synchronization via `graphify update .` after changes.
- Ingress routing must strictly comply with `docs/HOMELAB-SSOT.md` (Traefik File Provider at `/opt/ingress/dynamic/`, no direct public exposure).
- No secrets committed into the repository or workflows.
